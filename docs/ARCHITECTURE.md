# ROE WORLD architecture

This repo uses the complete r3f-starter capability stack as a ROE-native foundation.

## Core layers
- Next.js App Router
- React Three Fiber shared persistent canvas
- tunnel-rat scene injection
- Drei helpers
- Rapier physics
- postprocessing
- react-spring
- @react-three/uikit
- GLSL/glslify
- Zustand persisted world state
- Strudel browser music tooling

## Asset policy
The separate `mudasserali/ROEASSETS` repository remains the source archive. Production-ready website assets should be copied into `public/` in this repo so the deployed site never depends on private raw GitHub URLs.
